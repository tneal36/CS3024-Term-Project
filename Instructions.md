Secure Code Analysis and Remediation Project

Objective: The final term project for CSC 3024 Secure Code/Vulnerabilities I aims to provide students with hands-on experience in analyzing, exploiting, and securing software vulnerabilities. Students can choose from multiple focuses, allowing them to explore specific aspects of secure code development.

Project Focus Options:

Software Vulnerability Analysis:
    Vulnerability Assessment Report detailing identified vulnerabilities.
    Recommendations for addressing the identified vulnerabilities.
    Task: Choose a specific software application or system and conduct a comprehensive vulnerability analysis.
    Deliverables:
Code Generation for Compromised Software:
    Documented code showcasing intentional vulnerabilities.
    Explanation of potential exploits and risks associated with the compromised code.
    Task: Simulate a compromised software scenario by intentionally introducing vulnerabilities into a codebase.
    Deliverables:
Implementing Solutions for Compromised Software:
    Modified code demonstrating the implementation of secure coding practices.
    Detailed explanation of the applied solutions.
    Task: Select a compromised software scenario from Option 2 and develop solutions to rectify the identified vulnerabilities.
    Deliverables:
Evaluation and Security Enhancement:
    Report on the tools used for evaluation.
    Documented steps for securing the software, along with evidence of improvement.
    Task: Use current software tools to evaluate and enhance the security of a vulnerable software application.
    Deliverables:
Procedures for Vulnerability Reduction:
    Written procedures for secure code development.
    Guidelines for integrating security measures throughout the software development lifecycle.
    Task: Develop comprehensive procedures and guidelines for reducing vulnerabilities in software development.
    Deliverables:


Submission Guidelines:

Students must submit a proposal outlining their chosen focus and the specific software or scenario they will work on. The proposal should include a brief overview of the project's objectives and expected outcomes.
Progress updates must be submitted at designated intervals, including any challenges faced and solutions implemented.
The final submission should include all deliverables specified for the chosen focus.

Assessment Criteria:

Technical Proficiency: Demonstrated understanding and application of secure coding practices.
Comprehensive Analysis: Thorough examination of vulnerabilities, exploits, and solutions.
Documentation: Clear and concise analysis, code, and solutions documentation.
Adherence to Guidelines: Followed the guidelines provided for the selected focus.
Note: Students are encouraged to collaborate on knowledge sharing but are expected to complete the project individually. Plagiarism will result in disciplinary action. Consultation with the instructor is allowed for clarification and guidance.
